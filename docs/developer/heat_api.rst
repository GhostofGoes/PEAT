********
HEAT API
********
The internals of :term:`HEAT`: the extractor base classes and the extractors for each
protocol. The entry point, :func:`peat.api.heat_api.heat_main`, is documented with the
other commands in :doc:`peat_api`; how HEAT works from a user's point of view is in
:doc:`/user_guide/heat`.
